## 検索して見つけた項目まで到達できるようにする（2026-08-09・`feat/search-scroll-to-item`）

harutoさんの依頼「検索したら、その項目のとこまで移動するようにしたい」への対応。

- [x] **候補をタップしても絞り込まれない不具合を直した。**
      `query = item.name` の直後に `dismissSearch()` を呼んでいたが、
      `dismissSearch` は**検索フィールドの文字を消す**と規定されている。
      Appleが用意している `searchCompletion` へ差し替えた
- [x] **検索中は一覧より上のセクションを畳む。**
      一覧は画面のいちばん下にあり、絞り込んでも結果は画面外だった。
      レポート・大きな支払いの予告・これから出ていく・状態のピッカーを検索中だけ隠す
- [x] **検索中は状態（利用中／停止中／履歴）の絞り込みを外す。**
      候補は元から状態を見ないため、一覧だけ絞ると
      「候補に出たのに選ぶと見つかりません」になっていた。
      ピッカーを隠す以上、効いたままだと理由が画面に残らない
- [x] 見出しを「検索結果」に切り替える（`DashboardListHeading`）
- [x] ユニットテスト9件を追加。既存を含め464件が通る
- [x] **シミュレーターでの見え方の確認**（harutoさん・2026-08-09「いい感じ」）
