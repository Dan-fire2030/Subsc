# SPEC - 起動時チュートリアル

**確定日：2026-08-08**
ブランチ：`feat/onboarding-tutorial`（ベースは `design/black-cat-redesign`）

## 目的

**初めて開いた人が、何ができるアプリなのかを知らないまま空の画面と向き合う状態をなくす。**

いまの初回起動は `DashboardEmptyState`（費目0件の案内）だけで、
「費目を追加できる」ことしか伝わらない。借入の返済管理・変動費の実績入力・
レポートの読み方といった主要機能は、**画面を触って偶然見つけるしかない**。

## 対象範囲

**新規に足すのは1つの画面（全画面ページャー）と、その表示要否を持つ1つのストアだけ。**
既存画面の構造は変えない。

| 対象 | 内容 |
|---|---|
| 新規 | 全画面チュートリアル（4ページ＋スキップ・完了） |
| 新規 | 表示要否のストア（`UserDefaults`） |
| 変更 | `RootView` … 初回のみチュートリアルを被せる |
| 変更 | `SettingsView` … 「チュートリアルをもう一度見る」を追加 |
| 変更しない | ダッシュボード・費目・借入・レポートの各画面 |
| 変更しない | **`@Model` の保存プロパティ、CloudKitのRecord Type / Field** |

## 機能要件

### ページ構成（4ページ・この順）

1. **費目を登録する** — サブスク・通信費・光熱費・その他固定費。定額と、金額が毎月変わる変動費（月ごとの実績を入力できる）
2. **借入・ローンを管理する** — 借りたときの条件からでも今の残高からでも登録でき、返済予定表・残高・完済予定日が自動で出る
3. **レポートを読む** — 月間・年間の集計、期間の左右スワイプ、年払いは更新月に全額を計上する、先の月の大きな支払いを予告する
4. **通知とデータ** — 更新日前・返済日・月末の未入力を知らせる。データは端末と本人のiCloudにだけ保存され、外部サーバーへ送らない

### 操作

- 左右スワイプでページを送る。現在位置をドットで示す
- **どのページからでもスキップできる。** スキップと最後まで見た場合の扱いは同じ（次回から出ない）
- 最終ページの主ボタンは「はじめる」

### 表示条件

- **初回起動時に1度だけ**。表示要否は `UserDefaults` に持つ（端末ごと）
- **設定画面からいつでも見直せる。** 見直しても「見た」記録は消さない
- **既存の利用者にも出す。** このアプリはまだApp Storeへ出しておらず、
  TestFlightの配布先しかいないため、全員が「初めて見る人」として扱ってよい

### アクセシビリティ

- 各ページは1つの読み上げ要素にまとめ、見出しと本文を続けて読ませる
- **文字サイズを最大にしても内容が切れない。** 収まらない場合はページ内をスクロールさせる
  （固定高さで `clipped()` しない。レポートカードで同じ失敗をしている）
- `reduceMotion` のときはページ送りのアニメーションを外す

## 非機能要件

- **通信しない。** チュートリアルは静的な文言と、SwiftUIで描く表現だけで構成する
- **ビットマップ画像を新規に作らない。** 各ページの絵はSF Symbolsと、
  既存の猫（`CatCompanionView`）・パレット（`BlackCatPalette`）で構成する
  → 画像生成のCodex委譲が要らず、この機能単体で完結する
- 起動を体感で遅くしない。判定は `UserDefaults` の読み出し1回に留める

## デザイン方針

- **黒猫の配色をそのまま使う**（`BlackCatPalette`）。ライト・ダーク両対応
- **猫は1ページ目にだけ「案内」の姿で座らせる**（`CatMood.guiding` が既にある）。
  全ページに出すと、猫が説明役として喋っているように読めてしまう
- **猫の口調で文言を書かない。** 説明は普通の日本語で書く
- **境界線を引かない。** 面の明度差と余白で構造を作る（ホームと同じ方針）
- 1ページの本文は3行以内を目安にする。読まれないものを増やさない

## 変えないもの（壊してはいけない）

- **保存データの形**（`@Model` の保存プロパティ、CloudKitのRecord Type名・フィールド名）
  → **CloudKit Productionへの反映は発生しない**
- Bundle ID `com.tonaria.subsc`
- `DashboardEmptyState` の役割（費目0件のときの案内）。チュートリアルと文言を重複させない
- 既存の `@AppStorage("hasUsedReportPaging")` によるスワイプ案内。こちらは残す

## 進め方

1. 表示要否のストアを**TDDで先に作る**（初回は出す／見たら出ない／見直しても記録は消えない）
2. ページ1枚ぶんのビューを作り、4ページぶんの内容を流し込む
3. `RootView` へ差し込み、`SettingsView` に再生の導線を足す
4. ライト・ダーク両方と、最大文字サイズで確認する

## 受け入れ条件

- [ ] 初回起動でチュートリアルが出る
- [ ] スキップしても最後まで見ても、次の起動では出ない
- [ ] 設定画面から見直せる。見直した後も次の起動では出ない
- [ ] ライト・ダーク両方で読める
- [ ] 最大文字サイズで内容が切れない
- [ ] ユニットテストが全て通る（**データの形を変えないため既存テストは落ちてはいけない**）
- [ ] CloudKitスキーマの変更が無いことを確認する
