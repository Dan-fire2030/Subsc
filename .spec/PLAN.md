## ヒアリング済みの決定（2026-08-08）

- **形式：起動時の全画面ページャー。** 初回起動時に全画面で被せ、左右スワイプでめくる
- **伝える内容は4つ**（この順で1枚ずつ）：
  1. 費目の登録（定額・変動費）
  2. 借入・ローンと返済予定表
  3. レポートの見方
  4. 通知とデータの扱い
- **「見た」記録は `UserDefaults`（端末ごと）。** 設定画面からいつでも見直せるようにする
  - CloudKitスキーマを増やさずに済む（Production反映は不可逆なので、案内のために増やしたくない）
  - 2台目では再度出るが、新しい端末なら妥当と判断した
- **スキップは必ず付ける。** 飛ばせないチュートリアルは審査でも実利用でも嫌われる

## 前提・注意

- **ベースは `design/black-cat-redesign`。** チュートリアルは新UIを説明するものなので、
  リデザイン前の `main` から切ると意味が通らない。**同ブランチは main へ未マージ（52コミット差）**
- **保存されるデータの形は変えない。** `@Model` の保存プロパティと
  CloudKitのRecord Type / Field には触らない
- **猫の口調で文言を書かない**（リデザインで決めた方針。チュートリアルでも守る）
- 既存の前例：`ReportPager` が `@AppStorage("hasUsedReportPaging")` で
  「左右にスワイプ」の案内を初回だけ出し、**実際に操作したら消す**。この流儀に揃える
- 既存の `DashboardEmptyState` が「費目0件のときの案内」を担っている。**役割が重ならないようにする**
