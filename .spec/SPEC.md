# SPEC - パステルへの全面リデザイン（案A「マシュマロ」）

**確定日：2026-10-15**（`AskUserQuestion` で方針をharutoさんが決定）
ブランチ：`feat/pastel-redesign`（ベースは `feat/app-icon-pastel-circles`。アイコン差し替え済み）
デザインの正：キャンバス https://claude.ai/artifact/FmsSs4fc3mzRiLNmA13KCk の「案A」各画面とダーク版

## 目的

**暗くて見づらい画面を、明るく読みやすく、やわらかい画面へ変える。**
数字が主役なのは変えない。パステルは面（カード・背景・グラフ）に使い、文字は読める濃さを守る。

---

## 決まっていること

### 見た目の土台
- **ライトが主役、ダークにも対応**（端末の設定に従う）
- 色：白に近い地（ライト `#F8F7FC`／ダーク `#15131B`）。費目はパステル多色（ミント・ピーチ・ラベンダー・スカイ・バター ほか）
- **文字はパステルにしない。** 各カードの色相の濃い色にし、コントラスト比4.5:1以上を守る
- 書体：**システム書体のみ**（和文はヒラギノ角ゴ、数字は SF Rounded）。フォントは同梱しない
- 操作部品はiOS 26の標準（Liquid Glass のツールバー・タブバー）。自作のタブバーは作らない
- テーマ色（タブ・リンクの色）の既定値を金目からラベンダー（`#6A4FC9`）へ変える

### 猫
- **パステルに合う新しい猫**（丸い形だけで描く、ラベンダーの体・ピーチの頬）
- **さりげなく出す**：ホームの合計カードからのぞく／レポートの今月の棒に座る／カレンダーの肉球
- **気分は表情だけで出し分ける**（目・耳・小さな符号）。判定の `CatMood` はそのまま使う
- 今の黒猫の絵（`CatArt` / `CatArtworkData` / `CatPathParser`）は置き換えて削除する
- アイコンは K3（コミット済み）

### 画面の構成
- **ホームはデザインどおり分ける**：合計カード＋次の支払いカード＋費目の一覧（パステルの角丸カード）
- **レポートは別画面にする**。合計カードを押すと開く。期間の切り替え（月／年）と種別の絞り込みは残す
- **グラフの4種（帯・リング・バブル・縦バー）は残し、見た目を洗い直す**。設定で選べるのも残す
- カレンダー：支払い日のマスを費目の色で塗る。今の「マスに金額と件数を出す」切り替えは残す
- 登録・編集フォーム：項目構成は今のまま。上部に入力内容のプレビューカード、種別はボタン、カラーは色見本

### 進め方
- **このブランチに積み、全画面がそろってから main へ入れて TestFlight へ配る**（中途半端な状態を出さない）

## 守ること（既存の約束）

- **保存データとスキーマは変えない。** `@Model` に手を入れないので CloudKit の Production 反映は不要
- **旧パレットで保存された費目の色は書き換えない。** 表示のときだけ新パレットへ寄せる（今の `harmonizedHex` の仕組みを新パレットに向け直す）
- iOS 17〜25 は Liquid Glass が無い表示へ自然にフォールバックすること
- 文字サイズの拡大（Dynamic Type）で崩れないこと。タップ領域は44pt以上
- Swiftを変えたらコミット前にビルドとユニットテストを通す。UIテストはCLIで回せないのでXcodeでの実行を依頼する

## 承知しておくこと

- **App Store用のスクリーンショットはすべて撮り直し**になる（実画面をharutoさんが撮り、Codexが加工）
- テーマ色を自分で選んでいない利用者は、更新後に見た目が大きく変わる（それがリデザインの目的）
- 自分でテーマ色を選んだ利用者の色はそのまま残る
