# SPEC - カレンダー画面

**確定日：2026-08-09**
ブランチ：`feat/calendar-screen`（ベースは `main`）
見た目：`.output/design-system/components/calendar.html`（Claude Design にも同じものがある。2026-08-09に承認済み）

## 目的

**「いつ、いくら出ていくのか」を月のかたちで一望できるようにする。**

いまのホームは「これから出ていく」を時間軸で並べているが、**先頭の数件しか見えない**。
レポートは月ごとの合計は出すが、**月のどこに支払いが寄っているかは分からない**。
給料日との間隔や、支払いが重なる週を掴むには、月の形で見るのがいちばん早い。

## やらないこと

- **この画面から費目・借入を追加しない。** 追加の入口はホームの「＋」に一本化する。
  入口が散らばると、どこから足したかで挙動が違うのではという疑いが生まれる
- **金額の編集をしない。** 変動費の実績入力は既存の画面（`AmountEntryEditorView`）へ渡す
- **大きな支払いの予告は出さない。** ホームで既に扱っており、月の中では位置が意味を持たない
- **保存するデータを増やさない。** `@Model` に触らないため **CloudKitスキーマの反映は不要**

## 画面の位置づけ

タブは3つになる。**「ホーム」と「設定」のあいだ**に置く。

| 位置 | タブ | 役割 |
|---|---|---|
| 0 | ホーム | 状況の要約と一覧・操作 |
| **1** | **カレンダー** | **いつ出ていくかを月で見る（読むだけ）** |
| 2 | 設定 | 設定 |

`RootView` の `selectedTab` は現在 ホーム=0 / 設定=1。**設定のタグを2へずらす。**

## 表示するもの

### 1. マスに置く点

| 種類 | 元 | 色 | 形 |
|---|---|---|---|
| 費目の更新日 | `Subscription.renewalDate` | 費目の色（`harmonized`） | 塗った丸 |
| 借入・ローンの返済日 | `LoanPayment.dueOn` | 借入の色（`CostType.loan`） | 塗った丸 |
| 変動費の未入力 | その月の実績が `recorded` でない変動費 | その費目の色 | **塗らない輪** |

- **点は最大3つまで**並べ、超えたぶんは残数（`+2`）を出す
- 並び順は**その日の一覧と同じ**（後述）。点と一覧で順番が違うと対応が取れない
- **停止中の費目・完済した借入は出さない。** もう出ていかないため

### 2. 切り替えで出し入れするもの

**ツールバーのスイッチ1つ**で、次の2つを**まとめて**出し入れする。

- **その日の合計金額**（出ていく額。停止中は含めない）
- **件数のバッジ**（**2件以上のときだけ**。1件のときは金額が件数の意味を兼ねる）

決めごと：

- **切り替えてもマスの高さを変えない。** 月の形が動くと同じ月を見ている感覚が切れる
- **選んだ状態は覚えておく**（`UserDefaults`。`ThemeStore` と同じ流儀）
- スイッチは **iOS 26 で Liquid Glass、iOS 17〜25 は従来のボタン**へフォールバックする

### 3. 日の描き分け

- **今日**：金の輪だけ。塗りつぶさない
- **過ぎた日**：不透明度48%へ落とす
- **選んだ日**：カードの面（`surface`）を敷く
- **前後の月の日**：さらに淡く（22%）

### 4. 日をタップしたときの一覧

同じ画面の**カレンダーの下**に出す。

- 見出し：**日付（曜日）・件数・合計**（例：`8月30日（日）・3件・¥3,240`）
- 行はホームの一覧と同じ作り（左端の色の印・名前・カテゴリ／返済方式・金額）
- **停止中の費目も出す**（「停止中」バッジ付き）。**ただし合計には含めない**
- **変動費の未入力の行はタップで実績入力へ**（`AmountEntryEditorView`）
- 何も無い日：「この日に出ていくお金はありません。」

一覧の並び順：**借入 → 費目**、同じ種別の中は**金額の大きい順**、同額なら名前順。
**再描画で順番が入れ替わってはいけない**ため、最後は必ず名前で決める。

## 期間の移動

- **過去も未来も自由**。左右のボタンと横スワイプで月を移動する
- 起動時は**今日を含む月**を出し、**今日を選んだ状態**で開く
- **今日から離れているときだけ**「今日へ戻る」を出す（レポートの期間移動と同じ作法）

## 集計の決めごと

- **年払いは更新月に全額を計上する。** レポート・通知・一覧と揃える。1/12にならさない
- **変動費**：その月の実績があればその額、無ければ**見込み**を出し、
  **見込みは金額の後ろに「見込み」と添える**（断定しない）
- **米ドルの費目は円換算した額**を出す（`yenAmount`）
- **借入の返済額**はその回の予定額。**停止中・完済は出さない**

## テストで縛ること

ビューではなく、**日ごとの材料を組み立てる型**（`CalendarDayBuilder` 仮称）に対して書く。
`now` と `calendar` は**既定値付き引数で注入**し、実行日に依存させない。

- 月の日数と前後の月の埋め方（**うるう年・月またぎ**）
- 更新日・返済日がその日のマスへ入ること
- **停止中の費目と完済した借入が出ないこと**
- 変動費の未入力が、**その月の更新日のマス**に入ること
- 合計に**停止中を含めないこと**
- 年払いが**更新月に全額**で入ること
- 点が**3つで打ち切られ、残数が出ること**
- 一覧の並び順が**再描画で入れ替わらないこと**

## 受け入れ条件

- [ ] タブが「ホーム／カレンダー／設定」の順に並ぶ
- [ ] 既定で色の点だけが出る。スイッチで金額と件数が出る。**再起動しても選択が残る**
- [ ] 日をタップすると下に一覧が出る。停止中は出るが合計に入らない
- [ ] 過去も未来も移動できる。今日から離れると「今日へ戻る」が出る
- [ ] 過ぎた日が淡く、今日が金の輪で示される
- [ ] ライト・ダーク両方、**最大文字サイズ**で崩れない
- [ ] iOS 17〜25 でスイッチがフォールバックする
- [ ] ユニットテストが通り、**既存テストが1件も落ちない**
- [ ] **`@Model` に触っていない**（CloudKit反映が不要であることの確認）
