# SPEC - 黒猫モチーフの全面リデザイン

> PLAN：`.spec/PLAN.md`（2026-08-05）
> ヒアリング：2026-08-05 に3ラウンド実施

## 目的

Subsc の見た目を、**スタイリッシュな黒猫をモチーフにしたデザイン言語**へ全面的に張り替える。
現状のUIへの不満が動機ではない。**ブランドを作るための張り替え**である。

## 対象範囲

- **全画面の見た目**（ダッシュボード／費目一覧・詳細・フォーム／借入・返済／設定／通知の文言）
- **画面構成と導線は変えない。** タブの分け方、どこから何へ行けるかは現状のまま。
  変えるのは配色・タイポグラフィ・余白・部品の質感・イラスト表現
- アプリアイコン（**ビットマップ資産は2026-08-08以降**）
- アプリ名（**後回し。画面のデザインが固まってから決める**）

## デザイン方針

### 世界観

- 深い黒と金目のコントラスト。夜のしなやかさ。**上品で、装飾過多にしない**
- 黒猫は**ミニマルな幾何形**で描く。円と曲線だけで構成し、輪郭線に頼らない
- **SVG/ベクターで描く。** 解像度に依存せず、表情と動きをコードで変えられるため

### 配色

- **ライト・ダーク両対応。** 端末の設定に従う
- ダーク：墨色の地に金目のアクセント。ライト：白磁の地に墨の猫
- **既存の「テーマ色設定」は残す。** 選択肢を黒猫のパレットへ入れ替える
- **既存の「グラフの表示4スタイル」も残す。** 新しい配色へ合わせて描き直す

### 相棒の黒猫

- **常にダッシュボードに居て、状態に反応する**
- 反応させる状態（初版の案・実装時に確定させる）：
  | 状態 | きっかけ |
  |---|---|
  | 平常 | 特筆すべきことがない |
  | 心配 | 今月の支出が直近の平均より目立って多い |
  | ごきげん | 今月の支出が直近の平均より少ない |
  | 見張る | 大きな支払いが近い（既存の「支払い予告」と連動） |
  | 催促 | 変動費の金額が未入力のまま月末が近い |
  | 案内 | 費目が0件（初回起動直後） |
- **文言は猫の口調にしない。** 金額を扱う画面なので、表情と姿勢で伝える
- **金額の視認性を猫が邪魔しない。** 猫は主役ではなく、状況の要約を担う

## 変えないもの（壊してはいけない）

- **保存されるデータの形。** `@Model` の保存プロパティを増減させない。
  CloudKitのRecord Type名（`Subscription` / `Loan` / `LoanPayment`）とフィールド名も変えない
- **Bundle ID `com.tonaria.subsc`**（CloudKitコンテナとApp ID `6795086857` に紐づく）
- 画面構成と導線（上記のとおり）
- 年払いを更新月にだけ全額計上する集計（`monthlyAmount(forPeriodKey:calendar:)`）
- グラフの要素を `GlassEffectContainer` で包まない（ラベル・光沢・小さい円が消える）
- 審査向けの前提（独自ログインなし、通信は為替APIのみ、アプリ内課金なし）

## 進め方

1. **Claude Design（`claude.ai/design`）にデザインシステムのプロジェクトを作る。**
   配色トークン・タイポグラフィ・部品・猫のSVGをHTMLプレビューとして置き、
   ブラウザで見ながら選ぶ。**SwiftUIへ写すのは確定してから**
2. 確定した体系を SwiftUI へ落とす。画面単位で置き換える
3. ビットマップ資産（アプリアイコン）は **2026-08-08以降にCodexへ委譲**
4. アプリ名は世界観が見えてから決める

## 受け入れ条件

- [ ] ライト・ダークの両方で全画面が破綻なく読める
- [ ] 金額・日付が猫やアクセントに埋もれず、一目で読める
- [ ] 猫が上記6状態を正しく出し分ける（ユニットテストで状態判定を固定する）
- [ ] 既存のユニットテストが全て通る（**データの形を変えないため、落ちてはいけない**）
- [ ] テーマ色設定とグラフ4スタイルが新しい配色で機能する
- [ ] iOS 17〜25のフォールバック表示が崩れない（実機確認はharutoさん）
