## 試したこと・結果

### 成功したアプローチ

- **リファクタリングを「移動のみ」と機械的に証明した**：元ファイルと分割後6ファイルの結合を、`import`・docコメント・`private`修飾子を除いて行の多重集合として比較し差分ゼロを確認。目視確認が一部取れなくても振る舞い不変を示せた。手順は `.spec/KNOWLEDGE.md` に記録
- **ダッシュボードで `state.json` 方式を捨てた**：当初案は Claude が進捗を書き込む設計だったが、調査の結果 Claude Code が `subagents/agent-<id>.meta.json` と専用JSONLに全データを既に残していた。書き込みを廃したことで、書き忘れで画面が止まらず・進捗が本物になり・孫の自己申告も不要になった
- **実装前に「取れるか」を実データで確認した**：トークン数（`message.usage`）・ツール回数（`tool_use`）・任務内容（`meta.json` の `description`）・完了と要約（`<task-notification>` の `<status>`/`<summary>`）がすべて既存ログから取得可能と実測してから設計を確定させた
- **デモモード（`?demo=1`）を先に作った**：実エージェントの完了を待たずに4状態と孫世代を表示でき、見た目の調整が一気に楽になった

### 失敗したアプローチ・つまずき

- **非同期エージェントの `tool_result` を完了判定に使おうとした**：`tool_result` は**起動直後**に返る（`status: async_launched`）。これで判定すると全機体が即完了扱いになる。完了は `queue-operation` 内の `<task-notification>` の `<status>` でしか判定できない
- **`pkill -f "agent-dashboard/server.js"` に穴があった**：`cd ~/.claude/agent-dashboard && node server.js` で起動するとコマンドラインが `node server.js` になり取り逃がす。ポートを掴んでいるPID（`lsof -ti tcp:4317`）で止める方式に変更した
- **`timeout` コマンドが macOS に無い**：`timeout 2 cat` でフック入力を読む書き方が必ず失敗していた。スクリプト冒頭で読み切る方式に変更
- **シミュレーターMCPのタップ座標が合わない**：画像ピクセル（919x1879）とタップ座標（402x874ポイント）は単純な比率換算では一致せず、金額欄を押したつもりが一貫して「支払い周期」メニューが開いた。最後まで金額を入力できなかった
- **システムアラートに注入タップが届かない**：通知許可ダイアログを何度タップしても反応しない。`xcrun simctl privacy <udid> grant all <bundle-id>` で事前許可すると出なくなる
- **ロボットの腕がダーク背景に溶けて見えなかった**：`.arm` に独自の暗い塗りを指定していたため。`.shell` と同じ配色ルールに乗せて解決。バンザイの回転方向も逆だった（SVGの正回転は時計回り）
- **テストで zsh の `echo` が `\n` を実改行に変換し、JSONを壊していた**：stop.sh が動かないと誤認した。`printf '%s'` で再テストしたら正常だった
