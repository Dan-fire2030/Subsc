## 試したこと・結果

### 成功したアプローチ

- **不具合は「別件を追いかけている途中」で見つかった。** 7件のうち、狙って見つけたものは無い。
  月末のずれを直していて端数の1回増えを踏み、「何日前」通知を作っていて当日通知の欠落を踏んだ。
  **1つ直したら周辺をもう一度疑うのが有効。**
- **`Calendar` の挙動は推測せず、`swift` コマンドで実際に走らせて確かめた。**
  `2026-02-31` を要求すると `2026-03-03` が返ることを確認してから直した。憶測で書いていたら間違えていた。
- **CloudKitの代表データを2件に分けた。** `borrowedOn` と `startedTrackingOn` は登録方式で排他になるため、
  1件では両方のフィールドを生成できない。**先に気づけたのでフィールドの取りこぼしはゼロ。**
- **不具合を疑ったら、まずローカルのSQLiteを直接見た。**
  `~/Library/Developer/CoreSimulator/Devices/<UDID>/data/Containers/Data/Application/*/Library/Application Support/default.store`
  を `sqlite3` で読むと、履歴が空なのは「条件を満たすデータが無いだけ」とすぐ分かった。
- **Production反映前に差分を一覧で提示して承認を得た**（AGENTS.mdの要求どおり）。

### 失敗したアプローチ・つまずき

- **`project.pbxproj` に `+` を含むファイル名を裸で書いて壊した。**
  OpenStep plistでは `+` を含むパスは引用が要る。`xcodebuild: error: Unable to read project` になる。
  → `plutil -lint Subsc.xcodeproj/project.pbxproj` で必ず検証する。
  登録用スクリプトは `/private/tmp/.../scratchpad/add_files.py` にあり、引用処理を入れてある（**セッションが変わると消える**）。
- **UIDが2桁で足りなくなった。** 100以降は `BB000<NNN>0000000000000<NNN>` の形にした（24桁を維持）。**次に空いているのは 123。**
- **シミュレーターのキーボードが日本語のままで、ASCIIがかなに変換された。**
  `defaults write com.apple.Preferences AppleKeyboards` を書き換えて再起動しても直らなかった。
  → **変換候補バーの英字候補をタップして確定させる**のが確実。検証データの名前が英字なのはこのため。
- **数値入力欄の既定値「0」を消せない。** タップしてもカーソルが入るだけで、
  backspaceを送る手段がない。`1000000` と打つと `10000000` になる。
  → 検証データの金額が10倍・年利150%などになっているのはこれが原因。**スキーマ生成には影響しない。**
- **CloudKitのDeployが1回目に `XHR request failure` で失敗した。** 再試行で成功。**1回の失敗で諦めない。**
- **iCloudのパスワード再入力が必要になり、そこで止まった。**
  エージェントは認証情報を入力できない。haruto さんに入れてもらって解決。
- **既存テストが2件、バグ側の挙動を固定していた。**
  `testPausedVariableCostsAreExcluded` は「停止したら過去の月からも消える」を期待し、
  しかも `now` を渡さず実行日に依存していた。`LoanNotificationTests` は通知が0時である前提だった。
  → **期待値を直した。テストを緩めたのではなく、テストが間違っていた。** 報告時にその旨を明示すること。
- **テストの失敗理由がコンソールに出ない。**
  `xcrun xcresulttool get test-results tests --path <xcresult> --format json` を使うと
  `XCTAssertEqual failed: (...)` の実値が読める。**これを使わないと原因が分からず時間を溶かす。**
